# Baldness Probability Prediction

Data cleaning, exploratory data analysis, and a machine learning model that predicts baldness probability — built as a practice project on a deliberately messy synthetic dataset.

> ⚠️ **Note:** the dataset is synthetic (not real medical/survey data). Every pattern and correlation found here reflects the simulated data only and is **not a medical or scientific claim** about real-world causes of baldness. This repo is a data cleaning / EDA / ML technique exercise.

## Overview

- **Dataset:** `data/botak_kotor.csv` — 7,917 rows, 14 columns, deliberately "dirtied" (missing values in every column, duplicate rows) as a data-cleaning exercise for the Fullstack Bangalore AI Engineer Bootcamp.
- **Pipeline:** missing-value imputation (median/mode by column type) → duplicate removal → text/dtype cleanup → EDA (correlation, high-risk group analysis) → IQR outlier removal → feature encoding → 5-fold cross-validated model comparison → best-model selection.
- **Result:** Random Forest selected automatically (lowest cross-validation RMSE), achieving **R² = 0.856** and **RMSE = 0.0675** on a held-out test set.

## Results

| Model | CV RMSE (5-fold) |
|---|---|
| **Random Forest** | **0.074** |
| Support Vector Regression | 0.085 |
| Decision Tree | 0.103 |
| Linear Regression | 0.111 |

Feature correlation with `botak_prob` (strongest first): family history (0.44) > age (0.35) > stress (0.29) > smoking (0.26) > marital status (0.12) > salary/height/weight (~0).
